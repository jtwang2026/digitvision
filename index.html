START WITH A QUESTION

一张数字，如何成为一次预测？

DigitCNN 使用 MNIST 手写数字进行十分类：两组卷积、ReLU 和池化提取局部特征，再通过全连接层生成类别响应。页面呈现已记录的真实推理过程。

  1. 选一个样本和网络层先在二维页查看 Input、Conv1，再继续探索后续阶段。
  2. 播放，再停下来检查快速观察整体扫描，暂停后选择通道和坐标，打开计算详情。
  3. 把计算放进三维空间同时打开两个页面，在三维页开启“跟随 2D 空间进度”。使用同一个浏览器，保持二维页打开。
