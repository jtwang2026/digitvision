# DigitVision

Interactive CNN Learning Platform

Public website: https://jtwang2026.github.io/digitvision/

This repository contains the standalone static release, including real exported MNIST sample tensors and model weights. These exported data are publicly downloadable. No checkpoint, raw dataset, Python environment, credentials or development logs are included.

Known limitations and data disclosure: [Release notes](https://jtwang2026.github.io/digitvision/release-notes.html).

## Interactive experiences

- [2D Forward Pass Explorer](https://jtwang2026.github.io/digitvision/prototypes/forward_pass_explorer/)
- [3D Tensor Explorer](https://jtwang2026.github.io/digitvision/prototypes/tensor_explorer_3d/)
- [Convolution Playground](https://jtwang2026.github.io/digitvision/prototypes/convolution_playground/)

For synchronized exploration, keep both Explorer tabs open in the same browser and enable Follow 2D in the 3D page. First load downloads approximately 8 MB of real recorded data.
