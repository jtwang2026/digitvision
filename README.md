# DigitVision

Interactive CNN Learning Platform

Public website: https://jtwang2026.github.io/digitvision/

This repository contains the standalone static release, including real exported MNIST sample tensors and model weights. These exported data are publicly downloadable. No checkpoint, raw dataset, Python environment, credentials or development logs are included.

Known limitations and data disclosure: [Release notes](https://jtwang2026.github.io/digitvision/release-notes.html).
